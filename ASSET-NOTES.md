# Visual asset notes

Furniture and interiors were created with OpenAI image generation for this project. They contain no supplied company photography and must remain labelled as design inspiration, style reference or example configuration until actual Arezzi assets replace them.

- Original warm contemporary furniture scenes cover the listed sofa, bed and table directions.
- `hero/arezzi-mobile-living-room` is a separate portrait composition.
- Responsive WebP sizes are stored beside each image: full-size and `-640`.
- `materials/arezzi-fabric-selection` and `craftsmanship/arezzi-furniture-craftsmanship` are illustrative material still lifes, not exact certified material samples or an Arezzi workshop.
- `assets/video/hero-desktop.*` is a seamless crossfade sequence of generated scenes, not a transformation simulation.
- `assets/video/hero-mobile.*` contains gentle motion over the portrait composition.
- No actual Arezzi project, customer, employee, factory or showroom is depicted.
- The text-only brand area and generic furniture favicon are temporary placeholders for official branding.

Source PNGs are not required to run the site; optimized WebP and video assets are included locally. No external image hotlinks are used.
